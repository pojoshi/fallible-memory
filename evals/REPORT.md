# Eval report

Embedder: `hashing-256` (dim 256). Fused score = 0.7 x cosine + 0.3 x trigram similarity. Generated by `python evals/run.py`; do not edit by hand.

> The default hashing embedder is **lexical**: it matches shared words and character n-grams, not meaning. These numbers measure formatting and spelling robustness, and show where paraphrase matching fails, not what a semantic embedder would do. Re-run with `--embedder st:sentence-transformers/all-MiniLM-L6-v2` (needs the `ml` extra and a model download) to measure that.

Labelled data: 28 same-slot pairs, 24 different-slot pairs, 26 retrieval queries (small and hand-written, so treat differences of one or two items as noise).

## 2. End-to-end conflict detection

A stated fact is written under name A, then a conflicting inferred value under name B. The right behaviour for a same-slot pair is a recorded dispute; a miss means the memory now holds two unrelated-looking claims and will confidently answer from whichever slot is asked about.

| | conflicts detected | conflicts missed | different slots wrongly merged |
|---|---|---|---|
| exact-slot baseline | 1/28 | 27 | 0/24 |
| hybrid matching | 15/28 | 13 | 0/24 |

Of the 13 conflicts the hybrid matcher missed, 3 were flagged as a possible duplicate (shown in the retrieval note) rather than silently ignored.
